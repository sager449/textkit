What is HTML escaping?

HTML escaping is the process of converting special characters into HTML entities so they display as literal text instead of being interpreted as HTML code. For example, the character < becomes &lt;, and & becomes &amp;.

Unescaping does the reverse: it turns HTML entities back into their original characters. This is essential when you want to read code as human-readable text rather than as encoded markup.

Characters we escape

  • & → &amp;
  • < → &lt;
  • > → &gt;
  • " → &quot;
  • ' → &#39;

FAQ

What does escaping HTML mean?

Escaping converts special HTML characters like < > & " ' into their safe entity form (&lt; &gt; &amp; &quot; &#39;). This prevents browsers from interpreting them as HTML code.

Is this HTML escape tool free?

Yes — 100% free, with no signup or registration required.

Is my code stored anywhere?

No. All processing happens locally in your browser. Your code is never sent to any server.

When should I escape HTML?

Escape HTML whenever you display user input in a web page, insert text into HTML, or want to show code examples without the browser rendering them.

Does it support numeric entities?

Unescaping handles common named entities (&amp;, &lt;, &gt;, &quot;, &nbsp;, &#39;). Numeric entities like &#169; are also decoded automatically.
